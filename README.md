# MD Barbearia — Site

Site one-page da **MD Barbearia** (Rua das Três Marias, 207 – Parque Novo Santo Amaro, São Paulo - SP).

🔗 **Online:** https://raphaelmondego.github.io/md-barbearia-site/

## Destaques
- Hero com tesoura SVG cromada interativa: as lâminas abrem e fecham conforme o cursor se move, com partículas douradas e fios de cabelo caindo a cada corte
- Faixa animada de serviços, cards com preços, galeria com lightbox, depoimentos, mapa e CTAs para WhatsApp
- HTML/CSS/JS puros (sem frameworks), responsivo, SEO + Open Graph, lazy loading e acessibilidade

## Estrutura
```
index.html
css/style.css
js/main.js
```

## Antes de divulgar
- Os **depoimentos** (João, Rafael, Thiago) são textos ilustrativos — trocar por avaliações reais do Google/Fresha.
- As **fotos** são do Unsplash — trocar por fotos reais da barbearia quando possível.
- Confirmar horários e preços com o cliente.

GitHub Pages: Settings → Pages → Source: `main` / `(root)`.
